# URL Shortener

A simple backend application built using **Java, Spring Boot, and MySQL** that converts long URLs into short links and redirects users to the original websites.

## ✨ Features

- Converts long URLs into short URLs.
- Generates short codes dynamically.
- Checks whether a generated short code already exists before saving it.
- Stores original URLs and short codes in a MySQL database.
- Redirects users to the original website using the short URL.
- Supports API testing using Postman.

## 🛠️ Technologies Used

- **Java** – Backend programming language
- **Spring Boot** – Backend application framework
- **Spring Data JPA** – Database interaction and persistence
- **MySQL** – Stores original URLs and short codes
- **Maven** – Project and dependency management
- **Postman** – API testing

## ⚙️ Setup Instructions

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd <your-project-folder>
```

### 2. Create the MySQL Database

Open MySQL and execute:

```sql
CREATE DATABASE urlshortener_db;
```

### 3. Configure Database Properties

Update `src/main/resources/application.properties` with your MySQL configuration.

```properties
spring.application.name=urlshortener

spring.datasource.url=jdbc:mysql://localhost:3306/urlshortener_db
spring.datasource.username=your_username
spring.datasource.password=your_password

spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
spring.jpa.properties.hibernate.format_sql=true
```

Replace `your_password` with your actual MySQL password.

### 4. Run the Application

Open the project in Eclipse or your preferred Java IDE.

Run `UrlshortenerApplication.java` as a Spring Boot application.

The application will start at:

```text
http://localhost:8080
```

### 5. Test the APIs

Use Postman to test the URL shortening and redirection functionalities.

## 🧪 API Endpoints

### 1. Shorten a URL

Generates a short URL for the given original URL.

- **Method:** `POST`
- **Endpoint:** `http://localhost:8080/shorten`

**Postman Configuration:**

1. Open Postman and create a new request.

2. Select the `POST` method.

3. Enter the endpoint:

   ```text
   http://localhost:8080/shorten
   ```

4. Select **param&#x20;**

5. Enter the following parameter:

| Key           | Value                    |
| ------------- | ------------------------ |
| `originalUrl` | `https://www.google.com` |

6. Click **Send**.

**Example Response:**

```text
http://localhost:8080/a1b2c3
```

*The short code shown above is an example. The actual response depends on the code generated by the application.*

### 2. Redirect to the Original URL

Redirects the user to the original website associated with the short code.

- **Method:** `GET`
- **Endpoint:** `http://localhost:8080/{shortCode}`

**Example:**

```text
http://localhost:8080/a1b2c3
```

**How to Test:**

1. Copy the short URL returned by the POST request.
2. Open the URL in your browser.
3. The application redirects you to the original website.

## 🔄 How It Works

1. The user submits a long URL through the POST API.
2. The application generates a short code dynamically.
3. The application checks whether the generated code already exists in the database.
4. If the code already exists, another code is generated.
5. If the code is unique, the original URL and short code are saved in MySQL.
6. The application returns the generated short URL.
7. When the short URL is opened, the application retrieves the original URL using the short code.
8. The user is redirected to the original website.
